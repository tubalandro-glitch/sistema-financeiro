## 💡 Conceitos Fundamentais

```
1. CLIENT-SERVER
   Navegador (Client) ←→ Flask (Server)
   
2. HTTP METHODS
   GET   → Buscar dados
   POST  → Enviar dados
   PUT   → Atualizar
   DELETE → Deletar

3. CRUD
   Create → Adicionar (POST)
   Read   → Listar (GET)
   Update → Editar (PUT)
   Delete → Deletar (DELETE)

4. JSON
   Formato que navegador e servidor entendem
   {"tipo": "ENTRADA", "valor": 150.50}

5. DATABASE
   Tabelas com colunas e linhas
   Dados persistem entre sessões

6. FRONTEND vs BACKEND
   Frontend: Tudo que você vê (HTML, CSS, JS)
   Backend: Lógica nos bastidores (Python, Flask)
```
